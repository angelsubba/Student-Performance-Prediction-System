Student Performance Prediction System

Project Overview

The Student Performance Prediction System is a Machine Learning-based web application developed using Python and Flask.

It predicts student academic performance based on previous examination marks, attendance percentage, and daily study hours.

Objectives

- Predict student academic performance.
- Analyze important academic factors.
- Provide recommendations to improve student performance.
- Demonstrate the use of Machine Learning in education.

Technologies Used

- Python
- Flask
- HTML
- CSS
- Machine Learning
- CSV Dataset

Machine Learning Algorithm

K-Nearest Neighbors (KNN) is used to predict student performance by comparing input details with existing student records.

Input Features

1. Student Name
2. Previous Exam Marks
3. Attendance Percentage
4. Daily Study Hours

Prediction Categories

- Good Performance
- Average Performance
- Needs Improvement

How to Run the Project

1. Download or clone the project.

2. Open the project folder in VS Code.

3. Create and activate a virtual environment.

4. Install dependencies:
   
   "pip install -r requirements.txt"

5. Run the application:
   
   "python app.py"

6. Open this address in your browser:
   
   "http://127.0.0.1:5000"
   
8. Open the deployed website using the Live Website link provided below.

Project Files

- "app.py" – Flask web application.
- "train_model.py" – Model training script.
- "student_data.csv" – Student dataset.
- "student_model.joblib" – Saved trained model (if retained).
- "templates/index.html" – Website interface.
- "requirements.txt" – Required Python packages.
- ".gitignore" – Files excluded from Git.

Conclusion

This project demonstrates how Machine Learning can help analyze student academic performance and provide useful recommendations for improvement.
