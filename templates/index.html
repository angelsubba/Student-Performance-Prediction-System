About This Project

The Student Performance Prediction System is a Machine Learning based web application that analyzes students' academic details to predict their performance.

Factors Used for Prediction

  • Previous examination marks
  • Attendance percentage
  • Daily study hours

Prediction Categories

  • Good Performance
  • Average Performance
  • Needs Improvement

Machine Learning Algorithm

This project uses the K-Nearest Neighbors (KNN) algorithm to compare student information with existing dataset records and predict academic performance based on the three nearest records.
